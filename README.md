# TrendPulse

TrendPulse is a Python project for ingesting, cleaning, analysing, and visualising trend data.

## Project layout

- `data/`: raw and processed datasets
- `src/`: ingestion, analysis, and visualisation code
- `tests/`: automated tests
- `notebooks/`: exploratory analysis
- `results/`: generated summaries and charts
- `report/`: written findings
- `presentation/`: presentation assets

## Getting started

```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
pytest
python -m src.main
```
